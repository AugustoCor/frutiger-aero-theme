# Taking README screenshots

1. Open `screenshots/aero-showcase` as its own window (File > Open Folder). Its
   `.vscode/settings.json` hides breadcrumbs, tips and git, and shows only the file name in the title bar.
2. Right-click the status bar and hide Sign In, Antigravity, Claude Code and similar items.
   Dismiss notifications (bell icon > Clear All).
3. Check the glass is showing. It applies to every profile and window because it patches VS Code itself.
4. Shots:
   - [x] Daylight Glass: `src/skyForecast.ts` with Explorer open
   - [x] Deep Aqua: same layout, for comparison
   - [x] Split editor: `src/BubbleOrb.luau` | `styles/glass-panel.css`
   - [x] Menu or Command Palette open (glass popups)
   - [x] `theme-preview.jsonc` (the settings behind the look)
5. Save the images to `images/`, so they're next to the README and in the right place to link from it.
